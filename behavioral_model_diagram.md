# Behavioral Loop Diagram

This model illustrates how decentralized threat actor ecosystems can reinforce participation over time.

```text
┌────────────────────┐
│  Identity Formation │
│  "I belong here"    │
└─────────┬──────────┘
          ↓
┌────────────────────┐
│  Status Signaling   │
│  "I can prove value"│
└─────────┬──────────┘
          ↓
┌────────────────────┐
│  Access Progression │
│  "I get closer in"  │
└─────────┬──────────┘
          ↓
┌────────────────────┐
│ Deeper Investment   │
│ "This is part of me"│
└─────────┬──────────┘
          ↓
          └───────────────→ loops back to Identity Formation
